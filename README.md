# Blood Banking System – CLI Based

A **CLI-based Blood Banking System** developed using **Python and SQL**. This project is designed to manage blood donors, blood inventory, patient requests, and blood bank records through a simple command-line interface.

### Features

* Donor registration and management
* Blood group management
* Blood inventory management
* Search blood by blood group
* Add and update blood stock
* Blood request management
* Donor and patient records
* CRUD operations
* SQL database integration
* Python OOP-based architecture
* CLI menu-driven interface

### Technologies Used

* **Python**
* **SQL / MySQL**
* **Object-Oriented Programming (OOP)**
* **Command Line Interface (CLI)**

### Project Goal

The main goal of this project is to practice **Python OOP, SQL database management, CRUD operations, and backend project architecture** by building a practical blood banking management system.
